# Contributing to Mockmate

Thank you for your interest in contributing! We welcome issues, bug fixes, documentation improvements, and new features.

How to contribute

1. Fork the repository and create a branch for your change.
2. Open an issue describing the problem or feature if one doesn't already exist.
3. Submit a pull request describing the change, with tests or reproduction steps when applicable.

Coding guidelines

- Follow the existing project style. Keep changes focused and well-documented.
- For Python, add or update tests and keep dependencies in `backend/requirements.txt`.
- For frontend, ensure linting passes and run app locally.

Commit message format

- Use concise messages and reference the issue when relevant.

Review & CI

- Pull requests will be reviewed and merged once they meet quality and compatibility standards.

Contact

- If you need help, open an issue and tag maintainers.
